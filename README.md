Quiz Mind Game 🎯

A simple Java Swing-based Quiz Application that tests users with multiple-choice questions and calculates their score at the end.

📌 Features

* Interactive graphical user interface (GUI) using Java Swing
* Multiple-choice quiz questions
* Instant feedback for correct and incorrect answers
* Score tracking system
* Progress bar to show quiz progress
* Final result evaluation
* User-friendly design with colorful interface

🛠 Technologies Used

* Java
* Swing (GUI Framework)
* AWT (Abstract Window Toolkit)

📂 Project Structure

```
QuizMindGame/
│
├── QuizMindGame.java
└── README.md
```

Main Components:

Question Class

Stores:

* Question text
* Four answer options
* Correct answer index

QuizMindGame Class

Handles:

* GUI creation
* Question loading
* Answer checking
* Score calculation
* Final result display

🚀 How to Run

Prerequisites

* Java JDK 8 or higher installed

Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/QuizMindGame.git
```

2. Open terminal in the project folder.

3. Compile the program:

```bash
javac QuizMindGame.java
```

4. Run the application:

```bash
java QuizMindGame
```

🎮 Quiz Flow

1. Application starts with the first question.
2. User selects one of four options.
3. The system immediately shows whether the answer is correct or wrong.
4. Score is updated automatically.
5. Progress bar tracks quiz completion.
6. After the last question, the final score and performance message are displayed.

📊 Scoring System

| Score | Result                    |
| ----- | ------------------------- |
| 5/5   | Excellent! Perfect Score! |
| 3–4/5 | Good Job!                 |
| 0–2/5 | Try Again!                |
